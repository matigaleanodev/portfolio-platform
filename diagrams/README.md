# Diagram sources

The validated Archify overview replaces system.mmd, api-flow.mmd and deployment.mmd. Request and deployment details live in [architecture](../docs/02-architecture.md).

The JSON is the editable specification, rendered/ contains the standalone HTML viewer and PNG preview, manifest.json preserves the original validation and SHA-256 receipts, and LICENSE.txt retains Archify MIT attribution.

The README preview opens the published viewer. GitHub displays HTML as source; download the local HTML to open it independently. Spanish labels are preserved in both README languages.

Canonical source: [portfolio/content/diagrams](https://github.com/matigaleanodev/portfolio/tree/34856adee211f57ddb32a8573b9af9578d73235b/content/diagrams). Regenerate there and copy JSON, HTML, PNG and receipt together; never edit rendered files separately. No build dependency is added here. This is a reviewed snapshot, not a live host audit. The published viewer may advance independently of this copy.
