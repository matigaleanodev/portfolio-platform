# Resumen

[English](01-overview.md)

El frontend mantiene el contenido profesional, los posts y los artefactos de build. El navegador usa una sola API pública para salud, contacto, chat y suscripciones. El workflow de publicación entrega el manifiesto y el conocimiento editorial del chat a funciones del backend CDK.

La API NestJS y el stack editorial AWS SAM conservan vías de recuperación independientes para solicitudes HTTP e invocaciones editoriales.
