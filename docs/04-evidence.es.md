## Lectura y mantenimiento

La API representa un componente lógico con implementaciones compatibles; el frontend conserva contenido estático y la capa cloud automatiza publicación/suscripciones. Verificar la configuración efectiva antes de afirmar qué implementación recibe tráfico.

Los diagramas describen límites y relaciones; no certifican despliegues ni pruebas de producción. Mantener fuentes, HTML, PNG y manifest sincronizados mediante las herramientas de diagrams/README. La documentación técnica describe el sistema existente.
